# Подключение чата к ekt.kz

Статус на 23.09.2026: рабочий [отдельный чат](https://marindsain8n.ru/webhook/c2829b2f-91dc-4808-9af4-c027923c0d44/chat) опубликован; **на ekt.kz он пока не установлен**. У команды нет доступа к шаблону/админке сайта. Партнёр предоставил API только для чтения каталога. Реальная корзина сайта находится по адресу [ekt.kz/personal/cart/](https://ekt.kz/personal/cart/), а демонстрационная корзина проекта хранится отдельно в Supabase.

## Что увидели на сайте

На публичной странице есть каталог, ссылка на корзину и WhatsApp-кнопка, но нет места, где команда могла бы самостоятельно вставить свой скрипт. Названия элементов `bx_*` позволяют предположить Bitrix, но платформу и место установки должен подтвердить владелец сайта. Не пытайтесь добавлять товары через недокументированные внутренние AJAX-адреса: они могут зависеть от пользовательской сессии и CSRF-защиты.

Условия оплаты и доставки опубликованы на [ekt.kz/checkout-delivery/](https://ekt.kz/checkout-delivery/). [FAQ](https://ekt.kz/about/faq/) подтверждает возможность розничного заказа, но точное минимальное количество может зависеть от упаковки. Эти сведения синхронизируются в `terms` через `db/terms.sql`.

## Что должен сделать владелец сайта

1. Дать ответственному разработчику доступ к тестовому шаблону/админке или самостоятельно установить фрагмент [site/ekt-chat-embed.html](../site/ekt-chat-embed.html) в общий шаблон перед `</body>`. В исходник сайта **не добавлять** Basic Auth API, пароль БД или ключи OpenAI.
2. Для встраивания создать копию `ekt_assistant` в n8n и перевести её Chat Trigger в режим **Embedded Chat**. Нельзя просто менять текущий Hosted Chat: отдельная [демо-ссылка](https://marindsain8n.ru/webhook/c2829b2f-91dc-4808-9af4-c027923c0d44/chat) нужна команде. В копии надо обновить ссылки в cart-инструментах с `Chat Trigger` на новый триггер, подключить ту же Postgres Chat Memory к Chat Trigger и AI Agent, настроить загрузку истории из памяти и разрешённые origin `https://ekt.kz` (при необходимости также `https://www.ekt.kz`). После публикации взять точный production Chat URL из узла и подставить его в `REPLACE_WITH_EMBEDDED_CHAT_WEBHOOK_URL`.
3. Проверить чат на тестовой странице в десктопной и мобильной версии, в том числе расположение кнопки рядом с существующим WhatsApp, несколько сообщений в одной сессии и восстановление сессии после перехода на другую страницу. До успешного теста не ставить скрипт на все страницы.
4. Для **настоящей** корзины предоставить документированный серверный метод добавления товара, способ связать чат с авторизованной сессией покупателя, правила CSRF/авторизации и тестовый контур. Вызов делать только на сервере после явного подтверждения; клиентскому JavaScript нельзя давать Basic Auth. Затем заменить прототипную корзину и повторить тесты количества/остатка/ссылки.

Встраиваемый режим и CDN-фрагмент описаны в [документации Chat Trigger](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-langchain.chattrigger/) и [официальном пакете @n8n/chat](https://www.npmjs.com/package/@n8n/chat). Фрагмент подготовлен, но без доступа к сайту и отдельного embedded workflow **не считается установленным или проверенным на ekt.kz**.
