# Отдельный демонстрационный сайт

Публичный адрес: https://ekt-assistant-hackalem-2026.koncevojdanila10.chatgpt.site/

`index.html` — копия публикуемой статической страницы. Отдельный Sites-исходник зафиксирован коммитом `a1bc95395c0d85050d4b2b372fad464de477d007`; версия 1 опубликована. На странице встроен действующий hosted-chat workflow `ekt_assistant` через iframe и предусмотрена прямая ссылка на чат, если iframe не отображается.

Сайт не хранит учётные данные и не обращается к ekt.kz API из браузера. Запросы о товарах идут через n8n и Postgres/Supabase. Цена и остатки берутся из БД. Корзина пока прототипная и не меняет корзину ekt.kz, поскольку партнёр предоставил только методы чтения каталога. Размещение виджета на ekt.kz требует доступа владельца сайта.

Проверка 23.09.2026: публикация Sites завершилась успешно, режим доступа `public`, страница и вложенный чат отображаются в браузере. Прямой чат был ранее проверен запросами по артикулу, аналогу, доставке и подтверждению корзины.
