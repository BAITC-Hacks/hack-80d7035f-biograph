# AGENTS.md — ИИ-ассистент для чата ekt.kz (HackAlem, трек 10)

## Задача

Чат-ассистент интернет-магазина ekt.kz: наличие, характеристики, сертификаты, аналоги, условия покупки,
добавление в корзину ТОЛЬКО после явного «да» клиента, ссылка на корзину. ТЗ: docs/TZ.md.

## Стек

n8n (наш инстанс через MCP + локально docker), OpenAI (credential в n8n), Postgres/Supabase + pgvector,
ekt.kz API (Basic Auth — только в credentials n8n и .env, НИКОГДА в коде и репо).

## Правила

- Итог фиксируется в 18:00, коммит + push каждый час. Маленькие коммиты с понятными сообщениями.
- Эксперт должен запустить проект по README: docker compose up -d + .env. Любая новая переменная → .env.example и README.
- Секреты только в .env (в .gitignore) и credentials n8n.
- После любого изменения workflow → экспорт в n8n/workflows/*.json и коммит.
- Имена инструментов агента — английские, snake_case, уникальные, с описанием «когда вызывать».
- Агент не выдумывает цену и наличие — только из инструментов.
- Корзина меняется ТОЛЬКО через confirm_add_to_cart и ТОЛЬКО после явного согласия — проверка в коде, не только в промпте.
- Если нода не работает после 3 попыток — остановись и предложи проще.

## Команда

Даниал — агент и инструменты n8n. Ерканат — каталог, БД, корзина, UI, docker, деплой. Марина — условия покупки, тесты, README, питч.
