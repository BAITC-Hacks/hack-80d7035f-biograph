# ekt.kz AI assistant

Чат-консультант для ekt.kz: поиск товаров, характеристики, остатки по складам, сертификаты, аналоги и условия покупки. Цена и наличие берутся только из базы каталога.

## Быстрый запуск

1. Скопируйте шаблон окружения:

   ```powershell
   Copy-Item .env.example .env
   ```

2. Замените `POSTGRES_PASSWORD` и `N8N_ENCRYPTION_KEY` в `.env` на собственные секретные значения. Файл `.env` не коммитится.

3. Запустите локальный стек:

   ```powershell
   docker compose up -d
   ```

4. Откройте n8n: [http://localhost:5678](http://localhost:5678). При первом запуске создайте владельца n8n.

5. Создайте credential типа **Postgres** с параметрами из `.env`:

   - Host: `postgres` (если n8n запущен через этот Docker Compose);
   - Port: `5432`;
   - Database: значение `POSTGRES_DB`;
   - User: значение `POSTGRES_USER`;
   - Password: значение `POSTGRES_PASSWORD`;
   - SSL: выключен для локального Docker.

6. Импортируйте `n8n/workflows/ekt_assistant.json` и назначьте Postgres credential нодам `Postgres Chat Memory`, `search_products`, `get_product`, `find_analogs`, `purchase_terms`, `prepare_cart_intent` и `confirm_add_to_cart`. Выберите OpenAI credential в `OpenAI Chat Model`.

7. Импортируйте и опубликуйте `n8n/workflows/ekt_cart_view.json`, назначив Postgres credential ноде `Load cart`. В `confirm_add_to_cart` замените базовый URL `https://marindsain8n.ru/webhook/ekt-cart` на `http://localhost:5678/webhook/ekt-cart`, затем опубликуйте `ekt_assistant`. Для уже существующей локальной БД (том Docker создан раньше) однократно запустите `n8n/workflows/ekt_cart_schema.json`: новые init-скрипты выполняются автоматически только при создании пустого тома.

## Уже работающий облачный вариант

На https://marindsain8n.ru создан и опубликован workflow `ekt_assistant`. Его Postgres credential подключён к Supabase через Session pooler (порт 5432). SQL из [db/init.sql](db/init.sql), [db/cart.sql](db/cart.sql) и [db/terms.sql](db/terms.sql) выполнен в Supabase. Повторные проверки 23 сентября 2026 года подтвердили товар по артикулу, аналог при нулевом остатке, составной вопрос о доставке/оплате/минимальной партии, отказ от добавления и запрет количества сверх остатка.

Для загрузки репрезентативной выборки реального каталога используйте `n8n/workflows/ekt_catalog_import.json` (workflow `ekt_catalog_import`). Он по нажатию **Execute workflow** запрашивает детальные данные восьми товаров через Basic Auth API ekt.kz и обновляет `products` в Supabase по артикулу. Импорт проверен: восемь товаров получили реальные цены и остатки; повторный запуск обновит те же строки. Логин и пароль API хранятся только в HTTP Basic Auth credential n8n. Идентификаторы товаров для выборки находятся в ноде `Sample product IDs`; для расширения выборки замените их на идентификаторы из следующих страниц `/api/products?page=N`.

В API списка есть `id`, `article`, `name`, `price` и URL карточки. Надёжный остаток по складам и характеристики берутся из `/api/products/detail?id=...`. Если сертификат в детальном ответе отсутствует, поле сертификата остаётся пустым. Категория для импортируемых товаров выводится из пути URL карточки. Поле `embedding` у этих восьми товаров пока пустое; `find_analogs` использует сходство названий через `pg_trgm`, когда векторов нет. Синтетические записи `TEST-*` остаются в базе для демонстрационных проверок.

## Прототипная корзина

На хостинговом n8n опубликованы `ekt_cart_view` и обновлённый `ekt_assistant`. Корзина хранится в нашей БД, **не в корзине сайта ekt.kz**: предоставленный партнёром API содержит только чтение каталога, без метода изменения корзины. В чат сначала отправляют, например, «Добавь 1 штуку артикула 200300273_». Инструмент `prepare_cart_intent` проверяет товар и остаток, сохраняет намерение и просит отдельное подтверждение. Лишь на следующем сообщении «Да, добавь» / «Иә, қос» инструмент `confirm_add_to_cart` сверяет исходный текст клиента, сессию, срок намерения (15 минут), отдельное выполнение и текущий остаток, затем атомарно меняет корзину. При успехе выдаётся ссылка на актуальное состояние корзины. Без согласия и при превышении остатка корзина не меняется. Ссылка содержит случайный токен доступа; не публикуйте её публично. Заказ и оплата в прототипе недоступны.

Локально `db/cart.sql` и `db/terms.sql` выполняются при первом запуске пустого Postgres-тома. SQL идемпотентен. На уже созданной БД запустите workflow `ekt_cart_schema` вручную после `db/init.sql`: он также обновит проверенные условия покупки и уберёт демонстрационные ссылки на сертификаты. Этот workflow предназначен только для установки схемы и не публикуется. Секреты остаются в credentials n8n и `.env`.

## Данные

При первом создании локальной БД Docker выполняет [db/init.sql](db/init.sql). Скрипт создаёт:

- `products` с ценой, остатками, характеристиками, сертификатом, ссылкой на карточку и embedding;
- `terms` для доставки, оплаты и минимальной партии; содержимое `db/terms.sql` сверено с публичными страницами ekt.kz;
- `n8n_chat_histories` для истории чата по sessionId;
- `cart_sessions`, `cart_pending`, `cart_items` для прототипной корзины;
- синтетические записи `TEST-001`, `TEST-000`, `TEST-002` и `TEST-003`.

`TEST-000` имеет нулевой остаток, а `TEST-002` и `TEST-003` пригодны для проверки аналогов. Все `TEST-*` — синтетические записи, не реальные карточки ekt.kz; фальшивые ссылки на сертификаты удалены. Перед демонстрацией замените синтетические данные выгрузкой ekt.kz; Basic Auth API-данные хранятся только в credentials n8n или `.env`.

## Проверка

В чате workflow отправьте:

```text
Покажите товар по артикулу TEST-001
У товара TEST-000 нулевой остаток, предложите аналог
Какие условия доставки, оплаты и минимальной партии?
Добавь 1 штуку по артикулу 200300273_
Да, добавь
```

Ожидается: ответ с данными из БД, аналоги при нулевом остатке, условия доставки из `terms` и добавление в прототипную корзину только после отдельного подтверждения. Откройте полученную ссылку и проверьте товар и количество. Также проверьте отказ («нет») и количество больше остатка — корзина не должна меняться.


## Подключение к сайту

Проверен публичный сайт ekt.kz; подготовлены [инструкция для владельца сайта](docs/SITE_INTEGRATION.md) и [фрагмент для встраивания](site/ekt-chat-embed.html). У команды пока нет доступа к шаблону/админке, поэтому чат **не установлен на ekt.kz**. Предоставленный API позволяет только читать каталог, поэтому настоящая корзина ekt.kz не изменяется. Для установки и подключения настоящей корзины нужны доступ владельца сайта и документированный серверный метод добавления товара. Вложения (фото, PDF, Excel, Word) пока не обрабатываются; не заявляйте эту возможность на демонстрации.
