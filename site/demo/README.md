# Публичный демо-сайт ekt.kz

Адрес: https://ekt-assistant-hackalem-2026.koncevojdanila10.chatgpt.site/

`index.html` — самостоятельный статический сайт без сборки и внешних JS-зависимостей. Версия 2 опубликована 23.09.2026. Интерфейс адаптирован к мобильному экрану, отвечает потоком, показывает ожидание/ошибки и позволяет начать новый диалог. Секретов, цен и остатков в HTML нет.

Браузер отправляет POST JSON `{action: "sendMessage", sessionId, chatInput}` в опубликованный n8n Chat Trigger. Endpoint задаётся константой `ENDPOINT` в скрипте. Для своего n8n замените этот URL и разрешите origin сайта в CORS Chat Trigger.

Ответы поддерживаются как JSON `output` и как NDJSON `begin/item/end`. Для текущего n8n Content-Type может быть application/json даже у потока: формат определяется по содержимому. Текст выводится через DOM без innerHTML, ссылки ограничены HTTPS. Автоматических повторов запросов нет, чтобы не повторять подтверждение корзины при потере соединения.

История интерфейса и случайный sessionId находятся в sessionStorage вкладки; «Новый диалог» создаёт новый sessionId. Серверная память хранится отдельно в Postgres. Ссылка на демо-корзину содержит токен доступа — не публикуйте её.

Это независимое демо HackAlem, не установленное на ekt.kz. Корзина хранится в нашей БД и не оформляет реальный заказ. API партнёра предоставляет только чтение каталога. Вложения пока не обрабатываются. Подробности запуска и ограничения — в корневом README; результаты проверок — в TEST_REPORT.md.
