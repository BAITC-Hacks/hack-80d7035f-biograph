## Что ещё не выполнено / не проверено

- Это демо-корзина в нашей БД, не настоящая корзина ekt.kz. Нет API изменения корзины и доступа к шаблону сайта партнёра.
- На момент первоначального smoke-теста в базе было восемь реальных товаров. Обновление 23.09.2026: импорт №3191 расширил выборку до всех 40 товаров из предоставленных PDF, TEST-* сохранены. Это всё ещё не весь каталог ekt.kz.
- Полноценный семантический search_products и embeddings реального каталога не реализованы. Есть ILIKE и fallback сходства названий для аналогов; pgvector используется только для совместимых имеющихся векторов.
- Файлы/фото/Excel/Word/PDF как вход чата пока не обрабатываются.
- Наличие сертификата зависит от заполненности БД; выдуманные ссылки не выдаются.
- Docker fresh-install не выполнялся в этой проверке. README уточняет ручные credentials, импорт и публикацию после `docker compose up -d`; статический сайт разворачивается отдельно.
- Нет проведённого нагрузочного теста, независимого аудита всех Supabase grants/RLS и автоматического обновления всего каталога.

Вывод: работающий публичный текстовый MVP для демонстрации основных сценариев; не утверждать, что всё ТЗ выполнено на 100%.
